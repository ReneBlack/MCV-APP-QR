# Marca MCV

`mcv-logo-horizontal.png` es una versión horizontal preparada a partir de la lámina de marca facilitada por el usuario, con fondo transparente. Conserva el texto «MCV Ltda.» y «Servicios Industriales» y se utiliza únicamente como identidad de esta aplicación.

El logo está incorporado como imagen PNG en una URL de datos dentro de `Index.html`. Al copiar ese HTML a Google Apps Script no hay que subir imágenes adicionales, publicar carpetas de Drive ni depender de la disponibilidad de la web corporativa.
